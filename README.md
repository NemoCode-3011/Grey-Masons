# Grey Masons

A static company-website concept built with HTML and CSS, supported by custom typography and image assets.

## Built with

- HTML
- CSS
- Custom fonts and image assets

## Run locally

No package installation is required. Open `index.html` in a browser, or use a local static server to preview the page.

## Project scope

This repository contains a static frontend website. It does not include a separate backend service.
